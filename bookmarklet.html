One-click "View post" button for Pages CMS

Pages CMS doesn't have a native "open live URL" button — its buttons can only trigger GitHub Actions (which needs 2 clicks). So we made you a true one-click bookmarklet that:

  • Reads the post you're editing in Pages CMS
  • Opens preview.html?path=... in a new tab
  • If the post is published, it auto-redirects to the live page /blog/<category>/<slug>.html
  • If it's a draft or not yet built, it shows an instant preview from GitHub (no waiting 1-2 min)

Step 1 — Drag this to your bookmarks bar

On desktop: show your bookmarks bar (Ctrl+Shift+B / Cmd+Shift+B), then drag the button below to it.

📖 View Post

If drag doesn't work, right-click → Copy link address, then create a new bookmark and paste it as URL.

Step 2 — Use it

  1. Open Pages CMS → Blog posts
  2. Edit any post (or create a new one and save)
  3. Click 📖 View Post in your bookmarks bar — one click, new tab, live or preview.

Works for drafts too. The preview page fetches the raw markdown from GitHub and renders it instantly. When the post is published, the same bookmarklet redirects straight to the live URL.

What about the old "View post" button inside Pages CMS?

That button triggers a GitHub Action workflow (view-post.yml). It needs 2 clicks: CMS → "View run" → "View deployment". We kept it, but we made it open the same preview.html so drafts work. If you want pure one-click, use the bookmarklet above — it's what most Pages CMS users do.
