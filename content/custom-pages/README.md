# Custom Pages — create any new page from CMS

Create a new file here to make a new page like /press.html, /collab.html, /advertise.html etc.

Each file needs:
- title: SEO title (browser tab)
- h1: Headline on page (optional, uses title if empty)
- description: Meta description for Google
- body: Markdown content (rich-text in CMS)

Optional:
- slug: URL slug, e.g. press → /press.html. Leave empty to auto-generate from title.
- eyebrow: Small uppercase text above H1
- lede: Intro paragraph under H1
- hero_image: Uploaded image

Example: press.md → /press.html
